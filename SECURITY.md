# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.
Use GitHub's **private vulnerability reporting** (the "Security" tab, then "Report a vulnerability") on this repository.

Include what you found, how to reproduce it, and what it could affect. We aim to acknowledge reports within 3 business days.

## Supported versions

Only the latest release on the default branch is supported.

## Scope

In scope: sign-in, sessions, access to scripts, sharing, real-time editing, file import, the API.
Out of scope: social engineering, attacks on third-party services (Cloudflare, Resend), and denial-of-service by volume.

See [docs/SECURITY.md](docs/SECURITY.md) for how the system is protected and its known gaps.
